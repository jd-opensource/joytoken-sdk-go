# Security Policy

Please do not report security vulnerabilities in public issues or pull requests.

Use the hosting provider's private vulnerability reporting or security advisory channel. If that channel is unavailable, contact the repository maintainers through a private organizational channel and include only the information needed to reproduce the issue.

When reporting, include the affected version, runtime, reproduction steps, and potential impact. Redact credentials and customer data. We will acknowledge reports as soon as practical and coordinate disclosure after a fix or mitigation is available.
